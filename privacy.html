Colab Studio Personal

プライバシーポリシー

適用開始日：2026年11月10日

利用目的とアクセスする情報

本ツールは、本人のGoogle Driveにある既存モデルキャッシュの読取り・更新と、本人が有効にした生成物の保存にGoogle Drive APIを利用します。既存のファイルを扱うため、Googleの認証画面ではDrive全体の読取り・書込み権限を要求します。本人のアカウントであることを確認するため、メールアドレスとGoogleのアカウント識別子も取得します。

保存と転送

モデルと任意の生成物コピーは本人のDriveに保存します。処理に必要なファイルは本人が起動したColabへ転送します。生成物は本人のMacにも保存します。長期利用する更新用トークンはMacのKeychainだけに保存します。Colabには短時間有効なアクセストークンと、その実行環境だけに割り当てた接続情報を渡します。

利用と共有の制限

Google APIから取得した情報を広告、販売、第三者への独立した提供、汎用AIモデルの学習のために利用しません。本人が指示したファイル処理にだけ利用します。Google APIから取得した情報の利用と転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

保存期間と接続解除

Driveのモデルキャッシュと生成物は本人が削除するまで保持されます。Colabの一時データはその実行環境の終了に従って失われます。Googleアカウントの接続済みアプリ管理でアクセスを取り消せます。Macに保存した認証情報はKeychainから削除できます。接続解除だけでは既存のキャッシュや生成物は削除されません。

問い合わせ

個人用ツールのため、連絡先はGoogle認証画面に表示されるユーザーサポートメールです。データの取扱いを変更する場合は、このページとアプリ内の案内を更新します。
